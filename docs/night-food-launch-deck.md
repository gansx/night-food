# Night Food 家宴星球发布会 PPT 文案

> 这份文档是 `night-food-launch-deck.pptx` 的内容源与演讲参考。PPT 风格定位为发布会感：暗色舞台、暖橙高光、玻璃卡片、轨道与星球意象。

## 01. 封面

**家宴星球**  
Night Food

把点餐、任务和积分，变成一个家庭协作的小宇宙。

演讲提示：  
这不是一个餐饮后台，也不是一个企业系统。它是给家庭使用的协作平台，让家里的点餐、任务和积分有一个温柔但清晰的运行方式。

## 02. 家庭协作的真实问题

**家庭每天都在协作，只是缺少一个好界面。**

- 今天吃什么，经常散落在聊天记录里。
- 家务任务靠口头提醒，反馈感很弱。
- 孩子或家人完成任务后，奖励不够即时。
- 家主需要维护规则，但不应该变成“家庭管理员焦虑”。

演讲提示：  
家庭不是公司，但家庭每天都在发生协作。我们要做的是让这件事变轻、变清晰、变有趣。

## 03. 产品定位

**Night Food 是一个家庭协作式点餐与积分任务平台。**

- 家人点餐。
- 家主维护菜单。
- 家主发布任务。
- 成员完成任务获得积分。
- 积分回到点餐和家庭激励里。

演讲提示：  
它的核心不是“点餐”，而是“家庭内部的小型协作闭环”。

## 04. 两个入口

**Web 家庭端**

- 点餐
- 订单
- 任务
- 我的

**Admin 家主管理端**

- 菜单
- 订单
- 任务
- 积分
- 成员
- 规则

演讲提示：  
家庭成员需要简单，家主需要掌控。两个入口让每个人只看到自己真正需要的东西。

## 05. 核心闭环

**菜单 -> 点餐 -> 订单 -> 任务 -> 积分 -> 再点餐**

演讲提示：  
积分不是孤立数字。任务让积分产生，点餐让积分被使用，订单让家庭协作落到真实生活里。

## 06. 家庭端体验

**给家人用的，不是给管理员用的。**

- 看图点餐。
- 查看订单。
- 领取任务。
- 提交完成。
- 查看积分和家庭状态。

演讲提示：  
家庭端要足够轻，手机上打开就能用。复杂度留给系统，简单感留给家人。

## 07. 家主管理台

**家主不是老板，是家庭规则的维护者。**

- 菜单分类和菜品维护。
- 订单状态推进。
- 任务发布与审核。
- 积分调整。
- 成员和规则管理。

演讲提示：  
我们把家主需要操心的事情集中到一个后台，但不让它变得像传统管理软件。

## 08. 菜单系统

**菜单不是列表，是家庭餐桌的配置中心。**

- 分类管理。
- 菜品图片。
- 积分价格。
- 今日推荐。
- 上下架。
- 当前分类静默切换。

演讲提示：  
当分类越来越多，页面不能无限展开。现在菜单页已经支持单分类查看和静默切换。

## 09. 任务积分系统

**把家务变成有反馈的参与。**

- 家主发布任务。
- 成员领取任务。
- 指派给具体成员。
- 提交完成。
- 家主审核。
- 积分到账。

演讲提示：  
任务系统最重要的是反馈。完成一件事之后，系统马上承认这件事，这对家庭氛围很重要。

## 10. 权限与家庭邀请码

**一个家庭，一个空间，一个邀请码。**

- 家主创建家庭。
- 成员通过邀请码加入。
- 角色与访问状态可管理。
- 后台仅家主可进入。

演讲提示：  
家庭系统一定要有边界。不是所有人都应该拥有所有权限，但加入家庭要足够简单。

## 11. 体验升级

**从网页变成 App 感。**

- 移动端底部导航。
- 自定义下拉弹层。
- 静默筛选。
- 暗色玻璃主题。
- 云端部署。
- 线上 e2e 回归。

演讲提示：  
体验不是一次性完成的。项目里很多细节，比如下拉层级、移动端布局、静默切换，都是为了让它更像一个真正能用的产品。

## 12. 技术架构

**轻量，但完整。**

- Next.js App Router
- React Client Components
- Cloudflare Workers
- Supabase Auth / Postgres / Storage
- GitHub Actions
- Playwright E2E

演讲提示：  
这个架构适合个人项目和家庭级应用：成本低、部署快、云端完整、可持续迭代。

## 13. 云端闭环

**从代码到线上，每一步自动化。**

- GitHub 推送代码。
- Actions 构建 Web/Admin。
- 部署到 Cloudflare Workers。
- Supabase 提供数据库和认证。
- Playwright 验证核心流程。

演讲提示：  
项目不只是在本地跑起来，而是已经形成了一条从开发到上线的稳定链路。

## 14. 项目价值

**Night Food 的价值，是让家庭日常有了一个温柔的系统。**

- 点餐更清楚。
- 家务更有反馈。
- 积分更有意义。
- 家主更省心。
- 家人更容易参与。

演讲提示：  
好的家庭工具不是让家庭变得机械，而是让协作更少摩擦。

## 15. 未来路线图

**下一站：更有生命力的家庭小宇宙。**

- 积分商城。
- 家庭排行榜。
- 成就徽章。
- 消息提醒。
- PWA 安装。
- AI 菜单推荐。
- 家庭年度报告。

演讲提示：  
现在是核心闭环，未来可以继续变成更完整、更有情绪价值的家庭系统。

## 16. 结束页

**Night Food 家宴星球**  
让每一次点餐和每一次任务，都成为家庭协作的一部分。

演讲提示：  
用一句话收束：这是一个关于家庭参与感的项目。点餐只是入口，协作才是核心。
